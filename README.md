# Чусовая — Android

WebView-оболочка над живым пейзажем (`app/src/main/assets/index.html`) + foreground-сервис с уведомлением,
поэтому музыка продолжает играть при выключенном экране.

## Как получить APK
1. Создай на GitHub новый репозиторий и загрузи в него содержимое этой папки (Add file → Upload files, вместе с папкой `.github`).
2. Вкладка **Actions** → Build APK → дождись зелёной галочки (~3–4 мин).
3. Внизу страницы запуска, в **Artifacts**, скачай `Chusovaya-apk`, распакуй, установи `app-debug.apk` (разреши установку из неизвестных источников).

Обновить пейзаж: заменить `assets/index.html` и закоммитить — APK соберётся заново.
